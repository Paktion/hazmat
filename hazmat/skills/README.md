# Driver skills

Short playbooks loaded into the driver's system prompt, in file-name order. They encode how an
analyst works; they never contain sample content. Add your own (for example `50-acme-environment.md`
describing your signed internal tools, EDR paths or naming conventions) by dropping a markdown file
here or pointing `HAZMAT_SKILLS_DIR` at a directory of them. Skills come only from the trusted side.
